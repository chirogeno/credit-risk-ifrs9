# credit-risk-ifrs9
# Motor de provisiones IFRS 9 para riesgo de crédito

Modelo que estima la probabilidad de impago (PD) de préstamos personales y calcula sus provisiones por pérdida esperada siguiendo la lógica de IFRS 9.

**Datos:** histórico público de Lending Club (2007-2018). Son préstamos de EE. UU. de una plataforma, no de un banco europeo, por lo que IFRS 9 se aplica como ejercicio metodológico simplificado.

**Herramientas:** SQL (DuckDB), Python (pandas, scikit-learn, XGBoost), Power BI y Git.

**Estado:** en construcción. Primera versión prevista para el 13 de diciembre de 2026.
